## 1. 示例演示什么

一个电池供电的传感器节点，把读数存进滚动历史、周期性批量上传：

- **类型化可搬迁消息**（`pm_make<T>` + 可搬迁 trait 的项目审计范例），
  引用跨整理保持有效——**每次整理后与运行结束都逐条借用并重算校验和**
  （host 参考运行：9,053 次检查 0 失败，历经 22 次整理）；
- **pinned DMA 环**（`pm_make_pinned`，双缓冲切换式轮转：先配新、后放旧
  ⇒ 屏障在池内漂移——真实池碎片化的主要来源）；
- **标准整理流程**（COMPACTION_POLICY §6 逐步对应）：大块导出失败 → 只读
  建议 → 静默期 → `compact()` → 重试，**四种结局分别计数**（直达 / 救回 /
  整理后仍失败 / 建议劝退）；
- **监控循环**：`poll_compaction_advice` 低频轮询，只报 verdict 迁移，
  绝不自动整理。

host 参考运行（20000 tick，200 次导出）：**170 直达 / 13 救回 / 9 整理后
仍失败 / 8 建议劝退，22 次整理，0 拒绝**；载荷完整性 9,053 查 0 失败；
账目 OK；`validate` OK；确定性（同构建重跑逐字节一致，Debug 与 Release
计数一致；ASan+UBSan 干净）。

## 2. 负载设计的三次否决（都保留在示例头注释里）

1. **同尺寸 churn**（fragmentation 基准的教训）：`free()` 合并相邻块，
   永不碎片化 → 零事件。
2. **逐最老驱逐**：最老的条目地址最低，first-fit 把新条目填回原洞 →
   池自愈，整理路径仍是死代码（实测：历史只有 1 条存活）。
3. **随机过期单独使用**：到达率 0.047/tick 低于过期率，或占用 65% 时
   池顶尾巴永远满足导出——实测 200 直达 0 事件。

有效的机制是**服务器 ACK 批量冲刷**（每 1200 tick 随机清 ~40% 历史）：
一次事件在 pinned 屏障之间打开一大片**分散**空闲，其后的导出才会失败。
这是真实产品的节奏（服务端确认后清理缓冲），不是为触发整理硬造的。

## 3. 设备记录（S3，三次 sizing 实测）

导出需求的可用区间很窄，三次实测（App version 见各自抓取）：

| 导出尺寸 | 结果 |
|---|---|
| 8–16 KiB | **200 直达，0 次整理**——63% 占用（对象表 256 上限所限）下池顶尾巴 ~60–70 KiB 永远够用，流程沉睡 |
| 48 KiB | **193 直达 / 1 救回 / 6 整理后仍失败**，7 次整理 0 拒绝——流程触发，但双屏障下"整理也无济于事"占主导（与 RESULTS §5.8 的屏障搁浅机制一致） |
| 16 KiB + 500 tick 冲刷 | 0 事件——更高冲刷频率反而把池抽干（到达率不济），占用跌到 39% |

定稿：S3 导出 48 KiB（流程真实触发、结局如实展示），host 8 KiB（87% 占用，
救回路径可演示）。**"compact 没能救回"是密集屏障下的诚实主流结局**，
`export_batch()` 对全部结局都有产品式处理——这正是集成者要带走的代码范式。
各结局的计数由运行自报，不做承诺。

经典 ESP32（64 KiB zone / 90 条历史 / 12 KiB 导出）**未实测**——板子离线，
构建配置已就绪，"烧录 + 抓取"即可补。

## 4. 工具修正：serial_cap 的丢弃窗口

本轮发现 `tests/serial_cap.py` 的丢弃窗口固定 1.5 s：**上一轮运行超过
1.5 s 时，其输出尾巴会漏进本次抓取**——若尾巴含停止标记，抓取在别人的
verdict 上提前结束（本轮连续三次抓取被坑）。新增可选第 5 参
`discard-secs`（默认 1.5 不变），运行超过 1.5 s 的固件必须传大于自身
时长的值（示例传 6）。文档已写进工具 docstring。

## 5. 已知边界

- 设备结局计数依赖 sizing（本节第 3 节），**不可跨目标比较**；示例是
  集成参考，不是基准——性能数字一律以 `bench/` 为准。
- 经典板未实测；模拟器传感器/DMA 是确定性模式，不证明任何并发性质
  （单 owner + 静默期契约，示例注释明说）。
- CI 断言的是审计线与"流程确实触发"（`compactions: [1-9]`），不断言
  具体结局计数——sizing 调整不应破坏门禁，审计失败必须破坏门禁。
